## In this section

- [Recall and search](/api/memory/recall-search/)
  Run hybrid recall, direct search, and similarity queries.
- [Embeddings](/api/memory/embeddings/)
  Inspect embedding records, worker health, and projections.

For authentication and envelope conventions, start with the [HTTP API overview](/api/).
