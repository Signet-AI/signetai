## What Signet gives your agents

Signet keeps memory, identity, sources, and secrets outside any single model or harness. The daemon persists the raw record first, distills durable knowledge in the background, and selects bounded context when an agent needs it.

- Local-first storage with explicit provenance and soft deletion
- Hybrid recall across full-text search, embeddings, and the knowledge graph
- Portable identity and working memory across Claude Code, Codex, OpenCode, OpenClaw, Hermes Agent, Pi, and Oh My Pi
- Typed APIs and self-hosting controls for teams and custom integrations
